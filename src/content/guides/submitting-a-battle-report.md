# How to Submit a Battle Report

After playing a game, record the results so they count toward league standings.

## Prerequisites

- You must be signed in as a **member** (or higher role)
- Both players should have profiles with their factions set up

## Submitting a Report

Navigate to [Submit Battle Report](/battle-reports/submit) from the main menu or the battle reports page.

### Game Details

Fill in the top section with the game setup:

- **Event Date** — When the game was played
- **Season** — Which league season this game counts toward
- **Mission** — The mission played (from the official mission deck)
- **Deployment** — The deployment map used
- **Battle Points** — The points size: Combat Patrol (500), Incursion (1000), Strike Force (2000), or Onslaught (3000)

### Attacker and Defender

For each side, fill in:

- **Player** — Select the player from the member list
- **Faction** — The army they played (filtered to that player's profile factions)
- **Score** — Their final victory points
- **Outcome** — Win, Loss, or Draw

You can also optionally record:

- **Units Lost** — How many units were destroyed
- **Models Lost** — Total models removed
- **Tabled** — Check this if the player was completely wiped out

> The attacker and defender must be different players.

### Round Stats (Optional)

For more detailed tracking, you can add per-round statistics. Click **Add Round** to record each round's points earned, units lost, and models lost for both sides. You can add up to 5 rounds.

### Draft vs Published

- **Draft** — Save the report to finish later. Only you and admins can see it.
- **Published** — The report is final and visible to everyone. Published reports count toward standings and cannot be edited by non-admins.

## After Submitting

Your battle report will appear on the [Battle Reports](/battle-reports) feed. If published, the results automatically update the season leaderboard and standings.
