# How to Edit a Profile (Admin)

Admins can edit any member's profile, including fields that members cannot change themselves.

## Steps

### 1. Open the Edit Page

From **Admin > Users**, click the actions menu on the profile you want to edit and select **Edit User**.

### 2. Update Profile Information

**Profile section:**
- **Avatar** — Upload or replace the profile picture
- **Display Name** — Change the player's display name (must remain unique)
- **Bio** — Update the player's bio (up to 500 characters)

**Admin Settings section:**
- **Link ID** — Set or update the platform ID used for automatic account linking
- **League Role** — Switch between **Member** and **Organizer**

**Factions section:**
- Add or remove factions from the player's profile using the faction picker

### 3. Save

Click **Update Profile** to save changes.

## Admin-Only Fields

The **Link ID** and **League Role** fields are only visible and editable by admins. Members editing their own profile through [Profile Settings](/profile/edit) can only change their display name, bio, avatar, factions, and password.
