# How to Create a Profile

Admins can create profiles for players before they sign up for an account. This is useful for pre-registering league members so their names appear in battle reports and rosters right away.

## Steps

### 1. Navigate to User Management

Go to **Admin > Users** from the admin menu, then click **Create Profile** in the top right.

### 2. Fill in Profile Details

- **Display Name** (required) — The player's name as it will appear across the site. Must be 2-50 characters and unique.
- **Bio** (optional) — A short description, up to 500 characters.
- **Link ID** (optional) — A platform ID (such as a Discord user ID) that will be used to automatically link this profile when the player signs up. See [Linking a Profile](/guides/linking-a-profile) for details.
- **League Role** — Choose **Member** (default) or **Organizer**.

### 3. Select Factions (Optional)

Check the factions this player uses. The faction picker shows the full hierarchy: Alliance > Faction > Sub-faction. Factions can be updated later.

### 4. Submit

Click **Create Profile**. The profile will be created as **unlinked** — meaning it exists in the system but is not yet associated with an authenticated user account.

## What Happens Next

- The profile appears in the member directory and can be added to season rosters
- The profile can be selected as a player when submitting battle reports
- When the player eventually signs up, their account can be linked to this profile (manually or automatically via Link ID)
