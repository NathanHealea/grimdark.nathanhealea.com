# How to Edit a Battle Report

Admins can edit any battle report in the system, whether it's a draft or published. Members can only edit their own draft reports.

## Steps

### 1. Find the Report

From **Admin > Battle Reports**, locate the report you want to edit. You can identify reports by date, players, and status (Draft or Published).

### 2. Open the Edit Page

Click the actions menu on the report row and select **Edit Report**. You can also navigate directly from the report detail page.

### 3. Make Changes

All the same fields from the submission form are available:

- **Game Details** — Event date, season, mission, deployment, battle points, rounds played
- **Attacker / Defender** — Player, faction, score, outcome, units lost, models lost, tabled
- **Round Stats** — Add, edit, or remove individual round details
- **Status** — Switch between Draft and Published

> When editing round stats, the old round data is replaced entirely with the new data you submit.

### 4. Save

Click **Update Battle Report** to save your changes.

## Important Notes

- Admins can change the status from **Draft to Published** or **Published to Draft**
- Non-admin members cannot unpublish a report that is already published
- Changing a published report to draft removes it from standings calculations until it is republished
- If you change player assignments, make sure their faction selections are still valid for the updated players
