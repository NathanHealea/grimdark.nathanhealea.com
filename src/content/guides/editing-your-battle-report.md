# How to Edit Your Battle Report

You can edit battle reports that you submitted. Here's how.

## Steps

### 1. Find Your Report

Navigate to [Battle Reports](/battle-reports) and find the report you want to edit. Click on it to open the detail page.

### 2. Open the Edit Page

Click the **Edit** button on the report detail page. This button only appears on reports you submitted.

### 3. Make Changes

All the same fields from the submission form are available:

- **Game Details** — Event date, season, mission, deployment, battle points, rounds played
- **Attacker / Defender** — Player, faction, score, outcome, units lost, models lost, tabled
- **Round Stats** — Add, edit, or remove per-round details
- **Status** — Switch from Draft to Published to finalize the report

### 4. Save

Click **Update Battle Report** to save your changes.

## Restrictions

- You can only edit reports that **you submitted** — you cannot edit other players' reports
- You can promote a draft to **Published**, but you cannot revert a published report back to draft
- Season assignment is limited to the **current active season**
- Published reports require all fields to be filled before saving

> If you need to make changes to a published report that you can't edit yourself, ask an admin for help.
