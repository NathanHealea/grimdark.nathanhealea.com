# Submit a Battle Report

**Epic:** Battle Reports

## Summary

Allow members to submit a battle report capturing the players, factions, points, outcome, and mission played.

## Acceptance Criteria

- [ ] Authenticated members can submit a battle report
- [ ] Report captures: both players, their factions, point values, outcome (win/loss/draw), and mission
- [ ] Submitted reports are saved to the database
- [ ] Validation prevents incomplete submissions
