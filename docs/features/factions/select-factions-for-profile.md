# Select Factions for Profile

**Epic:** Factions

## Summary

Allow users to associate one or more Warhammer 40k factions with their profile. Factions can be selected during the profile setup flow and updated when editing a profile. Selected factions are displayed on the member profile page and in the member directory.

## Acceptance Criteria

- [ ] Profile setup flow includes an optional faction selection step
- [ ] Users can select multiple factions from the full list
- [ ] Selections are stored in the `profile_factions` join table
- [ ] Users can update their faction selections when editing their profile
- [ ] Selected factions are displayed on the member's profile page
- [ ] Member directory entries show each member's selected factions
- [ ] Users can only manage their own faction associations
