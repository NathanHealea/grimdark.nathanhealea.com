# Faction Selector Component

**Epic:** Factions
**Status:** Todo

## Summary

A reusable client component for selecting one or more factions from the available list. Used across multiple forms including profile setup, profile editing, and battle report submission.

## Acceptance Criteria

- [ ] Component fetches the full factions list and renders selectable options
- [ ] Supports multi-select for profile forms (select multiple factions)
- [ ] Can be configured for single-select in contexts that require it (e.g., battle report faction per player)
- [ ] Returns selected faction IDs to the parent form
- [ ] Works as a client component (`'use client'`) for interactive selection
- [ ] Reusable across profile setup, profile edit, and battle report forms
