# Browse Factions

**Epic:** Factions
**Status:** Todo

## Summary

A public-facing page at `/factions` that lists all available Warhammer 40k factions. Viewable without authentication so newcomers can see what armies are represented in the league.

## Acceptance Criteria

- [ ] `/factions` route is publicly accessible (no login required)
- [ ] Page lists all factions from the `factions` table in alphabetical order
- [ ] Each faction displays its name
- [ ] Page is a server component that fetches data directly from Supabase
